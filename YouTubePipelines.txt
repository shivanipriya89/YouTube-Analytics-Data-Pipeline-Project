SECTION A — PYTHON ETL
======================

Q1. Data Ingestion
Using Python/Pandas, load the following datasets:
- videos.csv
- channels.csv
- video_metrics.csv
- traffic_sources.csv

Display the first 5 records of each dataset.


Q2. Data Quality Check
Using Python, check the datasets for:
- Null values
- Duplicate rows
- Data types
- Missing video_id
- Missing channel_id

Create a simple data-quality report.


Q3. Data Cleaning
Clean the datasets using Python.

Tasks:
- Remove duplicates
- Convert dates to datetime
- Convert numeric columns to appropriate data types
- Handle missing values
- Standardize column names

Save the cleaned datasets into a cleaned_data/ folder.


Q4. Create an ETL Pipeline
Create a Python ETL pipeline:

Extract → Transform → Load

Extract the CSV files, transform the data, and load the cleaned data into MySQL staging tables.
