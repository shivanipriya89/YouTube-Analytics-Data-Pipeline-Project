# YouTube-Analytics-Data-Pipeline-Project
This is a Data Engineering Project of YouTube Analytics Data Pipeline.
In this Project an end to end data pipeline is constructed of YouTube datasets.In this Project Python is used for data cleaning,duplicates removal and pipeline construction,MySQL Workbench is used for SQL Analytics and answering of Business SQL Queries,Star-Schema DataWarehouse Design is also added in data modelling section of YouTube Analytics.Pyspark concepts are also used for joined dataframes creations and complex business sql scenarios solutions.Kafka is also added for real time data processing of pipeline and Tableau KPI Dashboard is added in Tableau.zip folder.Refer youtabs.twb file as Tableau Dashboard Workbook.
Refer YouTubePipelines.txt for Project Questions.The entire Project solution with questions is added in YouTubeAnalytics.zip folder.
Refer datasets.zip folder for Project raw datasets.
